# ShinLar — сайт шиномонтажа

Одностраничник на чистом HTML/CSS/JS. Без сборки, без зависимостей — открывается двойным кликом
по `index.html` и так же заливается на любой хостинг.

```
shinlar/
├── index.html          # вся разметка + микроразметка schema.org
├── css/style.css       # стили (чёрный холст, hairline-бордеры)
├── js/
│   ├── main.js         # меню, форма, карта, появление блоков
│   ├── tire3d.js       # 3D-колесо в герое (генерируется кодом)
│   └── vendor/three.min.js
├── assets/
│   ├── favicon.svg
│   └── og.png          # превью для Telegram/WhatsApp/соцсетей
├── robots.txt
└── sitemap.xml
```

Достаточно открыть `index.html`. Если нужен сервер (например, чтобы посмотреть с телефона в той же сети):


## Публикация

Самый быстрый путь — перетащить папку на [app.netlify.com/drop](https://app.netlify.com/drop):
сайт поднимется за минуту, дальше можно прицепить домен. Альтернативы: Vercel, GitHub Pages,
любой обычный хостинг — файлы статические, PHP и БД не нужны.

После публикации:
1. Прописать домен в `index.html` (`og:url`, `canonical`, JSON-LD), `sitemap.xml`, `robots.txt`.
2. Добавить сайт в [Яндекс.Вебмастер](https://webmaster.yandex.ru) и Google Search Console.
3. Подключить [Яндекс.Метрику](https://metrika.yandex.ru) — счётчик вставляется перед `</head>`,
   цели: клик по «Записаться в Telegram» и по номеру телефона.

## Заявки с формы

Сейчас форма подбора собирает текст заявки, копирует его в буфер и открывает чат
[@Shinlar_kzn](https://t.me/Shinlar_kzn) — клиенту остаётся вставить и отправить.

Если захочешь, чтобы заявка падала в бота автоматически — нужен прокси, потому что токен бота
нельзя держать в браузере. Схема: форма → serverless-функция (Netlify/Vercel) → `sendMessage`
Bot API. Функция на 15 строк, токен лежит в переменных окружения.

## Анимации

| Что | Где |
|---|---|
| Появление блоков каскадом при скролле | `.reveal` + `--d` (задержка), `js/main.js` |
| Индикатор прочитанного в шапке | `#navProgress` |
| Бегущая строка услуг (стоп при наведении) | `.marquee` |
| Подсветка карточки за курсором | `--mx`/`--my`, `.card::before` |
| Счётчик «30 мин» | атрибут `data-count` |
| Строки прайса по очереди | `.price.is-in` |
| Плавный аккордеон FAQ | `.faq__wrap` (grid 0fr → 1fr) |
| Блик по белой кнопке, параллакс плашки статистики | `.btn--primary::after`, `.hero__stats` |

Всё выключается системной настройкой «уменьшить движение» (`prefers-reduced-motion`),
а CSS-часть завязана на класс `js` — с отключённым JS контент остаётся видимым.

## 3D-колесо

`js/tire3d.js` строит колесо процедурно: резина — `LatheGeometry` по профилю сечения, протектор —
`InstancedMesh` из скруглённых блоков с переменным шагом (как на настоящих шинах, чтобы рисунок
не выглядел штампованным), диск — обод, пять спиц-лопастей, ступица, гайки в утопленных лунках,
за спицами — тормозной диск с перфорацией и неподвижный суппорт.

Текстуры тоже генерируются кодом на `<canvas>`: зернистость резины, кольцевые рёбра и надписи
`SHINLAR` / `205/55 R16` на боковине, ламели на блоках протектора, следы полировки на металле,
HDR-окружение со «софтбоксами» для отражений. Включены мягкие тени — спицы и протектор
затеняют сами себя.

Полезные ручки: `R` и `W` — радиус и полуширина шины, массив `rows` — ряды протектора,
`pitch` — цикл длин блоков, `wheel.rotation` — разворот колеса, `0.3` в
`spin.rotation.y += (0.3 + boost) * dt` — скорость вращения.

Если WebGL недоступен, вместо канваса показывается CSS-заглушка; при включённом в системе
«уменьшении анимации» колесо не вращается.

Шрифты подключены с Google Fonts CDN, файлов шрифтов в репозитории нет — прикладывать текст
лицензии не требуется. OFL запрещает только продажу самих шрифтов как отдельного товара;
использование на коммерческом сайте, модификация и встраивание разрешены, атрибуция не нужна.

Превью `assets/og.png` генерируется скриптом на Inter — системные шрифты Windows
(Segoe UI, Arial) в графике сознательно не используются: их лицензии не рассчитаны
на коммерческую графику вне продуктов правообладателя.
